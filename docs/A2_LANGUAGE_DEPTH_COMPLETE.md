## What this means pedagogically

Each A2 lesson now teaches more than a small fixed phrase bank. Learners see:

1. the core communicative phrases;
2. the same idea in nearby contexts;
3. words that commonly occur together;
4. another natural way to express the intention;
5. plausible learner errors and corrected forms;
6. open production tasks where more than one answer can be valid.

The purpose is lexical depth, naturalness, contrast and transfer—not inflating lesson counts.

## Audio boundary

Language-depth examples are currently reading/enrichment material and are not automatically added to the controlled audio inventory.

This preserves the existing audio source contract while allowing selective future recording based on learner value.

## Next professional step

Do **not** add another bulk language-depth layer immediately.

Next, build an A2 lexical/recycling audit that answers:

- which high-value verbs recur across units;
- which connectors recur with a new function;
- where useful collocations appear only once;
- whether formal/informal register is distributed sensibly;
- which depth examples should later receive audio;
- where transformation exercises can create retrieval rather than passive exposure.

Then add richer retrieval/transformational exercises in targeted batches.
