# A2 newcomer applications

These four original Dutch/Arabic applications extend the existing eight-unit course without changing the 48 lesson identities or the lesson-completion contract. The separate `/a2-newcomers` entry is linked from `/a2` and `/a2-practice`. It is available without an account, payment or prerequisite gate.

## Authored scope

| Application | Communication goal | Preparation lessons |
| --- | --- | --- |
| Municipal letter | Identify missing information, a deadline and the difference between receipt, completeness and an appointment proposal | Local forms, reply deadlines, appointment status |
| Digital help | Describe a blocked step, distinguish saving from sending, request explanation while doing the action yourself | Forms and procedural instructions |
| Language school | Distinguish an introductory meeting from a lesson; explain an attendance obstacle and discuss an option without assuming acceptance | Course questions, school instructions, appointment options |
| Volunteering | Understand task boundaries, distinguish independent ability from observation and request demonstration or feedback | Instructions, constructive feedback, polite disagreement |

Each application contains a 96–106-word written source and a separate 54–57-word spoken update; four evidenced questions per source; two changed-detail writing tasks; and two partner role-plays with prompts, optional models and self-review criteria. Preparation adds six vocabulary/form entries and three bilingual help phrases per application. Estimated time is an editorial suggestion (35 minutes), not a measured learner duration.

## Editorial boundaries

Every organisation, service rule, deadline, venue and workflow is fictional. A preparation panel explains this before each application's sources; the pathway also tells learners to follow the real organisation's correspondence and ask it about uncertainty. Nothing asserts a municipality's actual application requirements, childcare provision, language-school admission, benefit entitlement or digital-service workflow. The digital exercise uses invented data and explicitly excludes passwords/codes. It does not implement a real form submission.

Translations and model answers preserve person, time, negation, incomplete information and conditions. Comprehension evidence includes the actual premises: an incomplete request can become complete while its proposed appointment still requires confirmation; a changed meeting channel does not imply a changed schedule; observing a task does not mean independently taking responsibility for it. Each of the 32 new questions has targeted links to existing A2 lessons.

The texts are original educational writing, not official correspondence, official questions, approved translations or independently reviewed CEFR assessment. This addition improves material for a possible supervised municipal demonstration. It does not establish readiness for municipal procurement or a public service. Independent bilingual NT2 review, observation with newcomers and accessibility evaluation remain pending; the repository's existing audio and public-launch gates still apply.

## UX and state

The pathway offers goals, time guidance and a start action for each application. Preparation is available on demand before the four skill sections, including articles/plurals or useful verb forms, clarification phrases and lesson links. Dutch content has explicit `lang="nl"` / LTR; Arabic instructions remain RTL. Existing in-page skill links preserve temporary answers. A teacher/volunteer paragraph explains role switching and changed-detail practice without implying learner certification.

The all-completed map message derives its count from the unit summaries, replacing a stale forty-lesson label. Original unit-review navigation still ends at the cumulative review. Application navigation forms a separate four-item sequence. Listening remains gated by complete playback or explicit text assistance; assistance is labelled. Questions explain evidence and link missed concepts to lessons. Writing and partner models are optional self-review aids, not arbitrary Dutch grammar grading. Answers are in memory only, reset across navigation/reload, and grant no completion. No teacher dashboard, learner assignment, new personal-data field, account schema, storage key or microphone recording is introduced.
