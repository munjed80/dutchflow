# A2 targeted mediation reinforcement

Updated 2026-10-07. This pass follows the cumulative A2 final review and addresses the remaining mediation gap **inside existing lessons**, without adding a ninth unit or changing the audio bank.

## Scope

Three existing production tasks were revised so learners must relay current information to someone who did not receive the original message or instruction.

### Work coordination — lesson 7

`a2-clarifying-instructions`

The second task no longer asks the learner only to repeat instructions back to the supervisor. The learner now relays the ordered steps to a colleague who missed them:

- check the addresses first;
- put today's forms in the green folder;
- ask the colleague to confirm understanding.

This changes the discourse role from simple confirmation to short practical mediation while preserving the original sequencing and clarification objective.

### School/local messages — lesson 24

`a2-writing-a-relevant-reply`

The second task now asks the learner to explain an organiser's message to a sister who has not read it:

- registration still covers two people;
- a community-centre laptop is available;
- bringing their own laptop is also permitted;
- the learner asks which option the sister prefers.

The task deliberately preserves the distinction between **allowed**, **available** and **required**.

### Travel — lesson 27

`a2-reporting-a-travel-delay`

The second task now requires relaying current travel information to a third person:

- expected arrival is 16:20;
- the friend is waiting inside at the information desk;
- only current information is passed on.

The model keeps `naar verwachting` so an estimate is not accidentally presented as a confirmed arrival time.

## Why these three

The full A2 audit found that confirmation, alternative choice and scheduling were already strong. The missing breadth was not another topic but the ability to select useful information and pass it on accurately.

These three contexts provide spaced reinforcement across:

- professional/task communication;
- educational/local written information;
- travel disruption.

The cumulative final review already supplies the missing public-announcement listening format, so this pass intentionally does **not** rewrite earlier audio sources. That preserves published audio request identities and avoids unnecessary churn before recording.
