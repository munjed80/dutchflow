## Supporting tasks and evidence

- **Reading `a2-a-school-reading-afternoon`:** Friday reading activity 13:30–14:30; helpers arrive 13:15 at library. Helping optional, but all invitees reply before Tuesday 16:00 by email, including those unable to help. Helpers state fictional child's name/group. Books supplied, not prohibited. Four questions cover reply, arrival/start, fields and lack of necessity. Evidence contains the necessary premises, including the quarter-hour difference used to infer start time.
- **Integrated written source:** Noor registered two for Saturday 10:00/room 1 computer workshop. Confirm before Thursday 18:00 by email with name/count/laptop choice. Phone optional; own laptop permitted, loan available. Questions cover deadline/channel, complete required information and optional equipment.
- **Connected listening `a2-passage-school-local-messages`:** Saturday changes to 11:00/room 2. Existing two-person registration stays valid; laptops ready. No new reply if count unchanged. If it changes, email before Friday 12:00. This 52-word source changes event details and the condition/deadline for replying; questions cannot be answered by carrying over the written instructions.
- **Scenario `a2-replying-to-a-neighbourhood-invitation`:** Lina and sister want Saturday 14:00/room 3 drawing workshop. Ask about obligation, then deadline/channel. Staff requires advance email registration before Thursday 17:00 with name/count including applicant; phone optional. Two participants, no art supplies needed. Final summary describes the intended email, and confirmation follows receipt. Transfer declines a new Monday 19:00 invitation because of class while respecting an explicit request for all invitees to reply.
- **Integrated production:** decline Wednesday 18:00 school meeting with work reason and greeting/sign-off, writing on Monday before Tuesday 15:00 deadline. Partner exchange distinguishes Sunday 10:30 activity from Friday 16:00 registration, counts both participants and leaves the optional phone blank. Examples respond to the partner's actual information.
