# A2 final integrated review

Updated 2026-10-07. This delivery implements the main action from `A2_FULL_COVERAGE_AUDIT.md`: one cumulative A2 practice pack spanning all eight authored units without adding a ninth topical unit.

## Purpose

The final review tests **transfer**, not recall of one unit. It remains free guided practice and must never be presented as a CEFR score, certificate or validated exam.

The learner must:

1. read an unfamiliar practical notice;
2. separate deadline, start time, required items and optional activity;
3. listen to a later public-announcement style update;
4. replace superseded location, time, transport and lunch information;
5. keep one unchanged requirement (bring a pen);
6. relay only the current information to a third person;
7. ask a polite indirect clarification about an unresolved detail;
8. negotiate a meeting using a preference/reason, one clarification question and final confirmation.

## Scenario design

The written source announces a fictional Saturday workshop at wijkcentrum De Brug:

- registration by Wednesday evening via e-mail;
- doors 10:30, workshop 11:00 in room 2;
- bring a pen and lunch;
- coffee/tea free;
- bus 4 arrives 10:10, followed by an approximate ten-minute walk;
- optional neighbourhood walk at 13:30.

The later spoken announcement deliberately supersedes multiple facts:

- venue becomes school De Horizon, room 5;
- start becomes 11:30;
- bus 4 does not run; bus 7 arrives 10:50 at the school;
- lunch is now provided;
- the pen requirement remains.

The optional neighbourhood walk is not mentioned in the update. The second writing task therefore requires the learner to ask whether it still takes place instead of inventing an answer.

## Coverage

The pack references every A2 unit ID and deliberately combines skills from across the sequence:

| Course capability | Final-review evidence |
| --- | --- |
| past/current information | distinguish original plan from later current update |
| work/task coordination | identify required action and practical preparation |
| service-style information | formal notice and polite clarification |
| appointments/time | distinguish door/open/start and changed start time |
| shopping/quantity precision | preserve exact required item rather than infer extras |
| school/local messages | deadline, required versus optional information, relevant reply |
| travel | cancelled route, replacement bus, arrival time |
| social interaction | preference/reason, proposal, clarification and confirmation |

## Remediation

All eight final-review comprehension questions have one or two targeted lesson links. Wrong answers route back to the relevant source skill rather than to the final review itself.

Examples:

- deadline/e-mail → `a2-finding-a-reply-deadline`, `a2-writing-a-relevant-reply`;
- changed venue → `a2-reporting-a-travel-delay`, `a2-writing-a-relevant-reply`;
- replacement bus → `a2-agreeing-on-another-route`, `a2-reporting-a-travel-delay`;
- required versus no-longer-required item → `a2-understanding-school-instructions`.
