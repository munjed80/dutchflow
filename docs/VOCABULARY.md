# Searchable vocabulary library

`/vocabulary` brings the vocabulary notes from enriched lessons into one free library. It is linked from `/learn` and enriched lesson pages. It is a lesson index, not a comprehensive dictionary or a new proficiency assessment. Counts are derived from the current content, so new enrichment automatically appears after a rebuild.

## Content and search

The server calls `buildVocabulary` with the authored lessons and extensions. It explicitly projects only the term, kind, forms, Arabic explanation, source lesson, and referenced Dutch/Arabic example. Quiz answer banks and production models are not passed to the library client. Unknown lesson/example references fail rather than silently omitting content.

Repeated terms retain separate lesson contexts. A stable lesson/term key keeps cards distinct, while example audio and review use the existing phrase ID. No lesson, phrase, translation, audio ID or completion denominator is changed by this feature.

Search matches every whitespace-separated token across terms, plural/conjugated forms, Arabic meanings, example sentences/translations and source lesson titles. Search-only normalization folds case, combining accents, Arabic diacritics/tatweel and curly apostrophes; original displayed text is preserved. It is substring matching, not stemming, translation or fuzzy search. Type and module filters intersect with the query. Modules without enriched vocabulary are omitted from the filter.

The first 24 matches render initially. More results can be revealed in batches of 24. Query/filter changes reset that limit; clearing also focuses the search input. Query and filter state are temporary and reset on reload. All projected entries reach the client for instant search; revisit server-side search/pagination if the catalogue becomes large.

## Listening and review

Each audio button plays the full example sentence using the existing audio manifest/device fallback. It does not pronounce the headword in isolation. Filtering out a playing card unmounts the player and cancels playback. No MP3s are generated by this feature.

Saving is explicit and adds only the example phrase ID to the existing browser-local review list. Different words sharing a phrase share its saved status; repeated saves cannot duplicate the phrase. Read `REVIEW.md` for storage errors, retry, shared-browser identity and persistence. Vocabulary browsing, playback and saving never grant lesson completion.

## Validation

Native tests cover projection boundaries, same-lesson examples, repeated contexts, broken references, normalization and intersecting filters. Browser tests cover discovery, form search, combined filters, incremental results, clear/focus, source navigation, failed-save recovery, reload persistence, unchanged progress, mobile overflow and exact example playback/cancellation. Existing playback tests cover voice failures and stale events. Enrichment browser checks run independently per lesson to keep each content case within the normal timeout. These tests do not establish language accuracy or recorded voice quality.

Services/messages, home/neighbourhood and food/shopping enrichment are included in the current catalogue. The library indexes 162 contextual entries across 27 lessons; the around-town module is now available as a vocabulary filter. New content requires a rebuild, not a separate library inventory update.
