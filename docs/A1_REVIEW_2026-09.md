# A1 editorial review and remaining release gates — 2026-09-25

## Owner's scope

Complete and review A1, then generate stable lesson audio. Paid exams and A2 delivery are deferred. This change closes concrete content gaps; it does **not** declare A1 complete or claim independent educator sign-off.

## Review performed

Implementation-time review covered the existing 36 lesson phrase banks, Dutch/Arabic meanings, grammar notes, answer keys, dialogue order, vocabulary forms, the 14 reading passages and comprehension evidence, and the 16 starting-point questions. Existing scenario content is unchanged. Review checked meaning, internal consistency, single-answer intent, times, quantities and whether examples actually illustrate their headwords. It was performed by the coding assistant, not an independent qualified language editor. It cannot be represented as pedagogical validation or CEFR certification. New material underwent the same implementation-time check.

Specific repairs:

| Finding | Repair |
| --- | --- |
| `Er is ... warm water` accepted grammatical `wel` as well as intended `geen` | Explicitly ask for negation in the Arabic prompt |
| Doctor quiz and hobby quiz used nonsensical distractors | Replace them with natural Dutch alternatives with different meanings |
| Weather dialogue described the whole day as dry, then afternoon rain | Change the first weather report to `Vanochtend` and align translation |
| School dialogue implied a fever-based return rule and confirmed tomorrow prematurely | Teacher asks about tomorrow; parent says it is unknown and will call; teacher awaits the update |
| Absence reading repeated the implied return rule | Replace it with an explicit next-morning callback; align translation, evidence and answer key |
| `sinds vannacht` explanation invented an approximate midnight onset | Keep only “since last night” |
| Homework forced an unsuitable plural into a beginner vocabulary card | Use an explicit context-specific uncountable marker; allow that marker in validation |
| `de ouders` was displayed as a dictionary singular | Use `de ouder` with `de ouders` and explain parent/guardian |
| Hobby headword did not occur in its cited phrase | Use `lezen` with the actual reading question |
| Phrase lists alone left several lessons without productive support | Add six contextual notes and two transfer tasks to every previously unsupported lesson |

Mobile phrase cards also place audio controls below the text so long number lists keep a readable width.

Spoken text edits affect only `a1-weather-today-02`, `a1-message-to-school-07`, and `a1-message-to-school-08`. No recorded assets exist to migrate. All original 101 protected spoken texts and all existing lesson/phrase IDs survive. New content adds 40 IDs. The audio pipeline now fingerprints content so future edits cannot silently reuse stale recordings. Review cards for the three edited IDs intentionally show the corrected current content.
