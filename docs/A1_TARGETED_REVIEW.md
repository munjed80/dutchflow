# Targeted A1 practice review

The reading library and integrated reading/listening packs now offer lesson links based on the learner's **currently checked incorrect answers**. This closes the gap between seeing an explanation and finding a relevant lesson to study next. The links are teaching suggestions, not diagnoses of proficiency.

## Authored coverage

`src/data/a1-review-links.json` maps all 180 question IDs (90 library reading questions and 90 integrated reading/listening questions) to one or two existing lesson slugs. Selection follows the communicative or language demand: Dutch clock time, duration, quantities/prices, appointments, clarification, location, school messages, and so on. Numerical inference questions can link both the time/number foundation and the contextual application lesson.

This separate file adds no lesson audio or account changes. The 2026-09-29 hash snapshot in `A1_DETAILED_REVIEW.md` remains a historical review record for the earlier bank; later enrichment waves require their own follow-up editorial verification. Real recordings already generated by the owner remain compatible because the lesson/audio source IDs are unchanged.

## Feedback and state

- Suggestions appear only after every question is answered and the learner checks the attempt. An unanswered or unchecked choice produces no recommendation.
- Only incorrect answers contribute links. Each lesson appears once, accompanied by the relevant displayed question numbers. Reading and listening maintain separate lists.
- Editing an answer hides the old result and suggestions until rechecking. All-correct attempts show no remedial list. Retry, listening restart, reload and navigation clear suggestions with the existing attempt state.
- Correcting a listening answer after feedback remains text-assisted under the existing listening contract. Review links do not unlock questions, complete playback, grant completion or save answers.
- The links open existing lessons. Copy tells the learner that leaving the page clears the attempt. A named navigation region exposes the list; keyboard focus still moves to the result after checking, and to the first question on retry.
- The listening retry button says “أعد أسئلة الاستماع”; reading retains its own label.
- Integrated packs link to the next pack. The final review returns to the pack index instead of implying that another attempt or level starts automatically.

`getQuestionReviewLessons` resolves titles on the server and projects only the current quiz's `{ slug, title }` links. Client components use type-only imports from that module; they do not import the complete mapping or lesson catalogue. `ReadingQuiz` keeps its optional link prop so existing callers without mappings retain their original behavior.

## Authoring and verification

Add or revise the mapping whenever a question is added, removed or changes its learning objective. Choose the lesson based on what the learner needs to practise, not merely the module name. Do not use unpublished routes, duplicate targets, generic URLs or more than two targets per question. Recheck relevance editorially; automated validation proves links exist, not that they teach the right skill.

`validateReviewLinks`, included in `content:check`, rejects missing/stale question IDs, invalid targets, duplicate lessons and oversized recommendations. Native mutation tests verify these failures. Browser tests cover checked-only visibility, deduplication, question numbers, all-correct results, stale-advice removal, keyboard focus, actual lesson navigation, separate reading/listening lists, listening reset, mobile overflow and next-pack boundaries. Existing reading and passage-listening checks protect grading/evidence and assistance behavior.

No storage, account, payment, speech recognition or readiness-status changes are included.
